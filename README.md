
# Wilson Movies

An ASP.NET Core MVC web application developed for BYU-Idaho CSE 325.

## Live Application

[Visit Wilson Movies](https://wilson-movies-project.onrender.com/movies)

## GitHub Repository

[Wilson_Movies_Project](https://github.com/willlyca31-lab/Wilson_Movies_Project)

## Technologies Used

- C#
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQLite
- Razor Views
- Bootstrap
- Docker

## Application Features

- Movie listing and details
- Create, edit, and delete movie records
- Search movies by title
- Filter movies by genre
- Movie ratings
- Data validation

## Project Purpose

This project demonstrates the development of an ASP.NET Core MVC application, including database integration, CRUD operations, searching, and validation.
